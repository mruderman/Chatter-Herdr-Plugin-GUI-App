## Decisions (proposed numbers)
- **Q2** decided by Flan, 2026-10-09: `/brief` and `/role` are out of M3. They need new bridge routes and `chatter brief --json` is unverified. Tracked as debt.

- **D17** Notifications show the sender and "mentioned you" or "DM", never message text. Permission is asked on a button press.
- **Dependencies** exact pins, resolved with `npm install --before=2026-09-25` (two weeks before 2026-10-09) so transitive packages predate the cutoff too. `ignore-scripts=true` where the toolchain allows.

### T1 Bridge: static serving and CSP
Serve a built SPA from `CHATTER_BRIDGE_STATIC_DIR` at `/`, zero dependencies, no change to anything else. Tests first: write them, watch them fail, then implement.
- Config: a `staticDir` option on `createBridge` and the `CHATTER_BRIDGE_STATIC_DIR` environment variable in `bridge/bin/chatter-bridge.js` (help text and README table too). If set but not a directory containing `index.html`, fail at startup with a clear message. If unset, behaviour is byte-identical to today.
- Routing: `/healthz` and `/v1/*` are handled first, exactly as today. Static handling applies only to `GET` and `HEAD` on other paths. A `/v1/*` path that does not match a route stays a JSON 404.
- Resolving a path: percent-decode once and reject invalid encoding (400); reject NUL, backslash and `..` after normalisation; any segment starting with `.` is a 404; resolve with `fs.realpath` and require the result inside `realpath(staticDir)` (symlink escape is a 404); only regular files (no directory listing; `/` maps to `index.html`).
- SPA fallback: only when the path has no file extension, the request `Accept` includes `text/html`, and the path is not `/healthz` or under `/v1`. A missing path that has an extension, such as `/assets/x.js`, is a 404, never `index.html`.
- Headers on every static response, including the fallback: the D15 CSP exactly as written, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `X-Frame-Options: DENY`, a correct `Content-Type` (html, js, mjs, css, json, svg, png, ico, webmanifest, woff2, txt; anything else `application/octet-stream`), `Content-Length`. `Cache-Control: no-cache` for `index.html` and the fallback, `public, max-age=31536000, immutable` under `/assets/`, `no-cache` otherwise. `HEAD` returns headers without a body. Stream files with errors handled; never log tokens or full request headers.
- Tests (`bridge/test/static.test.js`, `node:test`): every rule above, plus encoded and double-encoded traversal, symlink to a file and to a directory outside the root, dotfiles, directory request, `HEAD`, content types, cache headers, and that `/v1/*` and `/healthz` behave as before. `makeEnv` in `helpers.js` gains a `staticDir` option, used by the integration cases and later by T4.

### T1b Static server follow-ups from the G0 review, round 1
Codex reviewed `616ccb9` read-only and found three Medium issues and one Low coverage gap in `bridge/src/static.js`. The coordinator reproduced each against the real CLI and ran all 17 mutations Codex proposed (16 were caught). Decisions: patch findings 1 and 3 and the coverage gap; do not patch finding 2. You hold only `bridge/src/static.js` and `bridge/test/static.test.js`. Add tests; never weaken or delete an existing one. Read both files in full first.
1. **Escape symlink with a missing child gets the SPA fallback.** Reproduced: with `escape-dir` a symlink to a directory outside the root, `GET /escape-dir/not-created` (Accept `text/html`) answers 200 with the shell, and an extensionless dangling symlink `/dangling` does too, while `/escape-dir/exists.txt` correctly answers 404. The brief says an escape is a 404 with no fallback. Required, for HTML requests to extensionless paths: a path whose existing prefix passes through a symlink that resolves outside the real root is a 404 whether or not the final component exists; a dangling symlink anywhere on the path is a 404 whatever it points to; an ordinary missing child under a real directory inside the root, at any depth (`/a/b/c`), is still the shell; a symlink loop is never a 500 and never an escape. Keep resolving once per request and keep opening the resolved path (the checked file is the served file). Keep it small and obvious; one helper used by `openInside` is the intended shape.
2. **Content-Length framing.** Reproduced: with a 32 MB file truncated in place while a paused client held the response, the client stopped at about 2.8 MB of the declared 33.5 MB and waited for the rest. Required: a response never writes more than the `Content-Length` it declared (read at most `size` bytes; a zero-byte file sends no stream), and a short read destroys the connection instead of leaving a keep-alive client waiting. `res.strictContentLength = true` before `writeHead` is the intended mechanism; verify on Node 22.16 that it behaves as documented. Test deterministically: a paused client plus an in-place truncation must see an error or a close within a bound, never a hang; and an in-place append while the response is in flight must deliver exactly `size` bytes.
3. **Descriptor closure (Low, coverage).** Removing `await handle.close()` from `sendFile`'s `finally` leaves all 24 tests green. Add a test that counts open descriptors through `/proc/self/fd` (Linux only; skip with a stated reason elsewhere) around many GET, HEAD, aborted-mid-stream and refused requests, and returns to the baseline.
4. **Not patched, by decision.** A malformed, NUL or backslash component that the URL parser removes through a following `..` (for example `/%ZZ/../index.html`, which answers the shell). Dot-segment removal is standard, the dropped component never reaches the file system, and validating the raw request line would add request-target parsing to security-critical code for no security gain. Do not change this; mention in your report if you disagree.

It also found that `res.end()` throws inside pipeline's own listener once `strictContentLength` is on, which would have crashed the process, so `sendFile` ends the response itself with `pipeline(..., { end: false })`. All 31 mutations (8 for the new guards, 6 of mine, 17 of Codex's) are caught by a named test.
