- **Name collisions, a design question (R-number to be assigned):** Chatter resolves a name it does not know exactly as the one agent whose name begins with it, so since T13 the bridge fails closed on it. SPEC section 6 already forbids a handle that equals an agent's name. Recommended default: leave it (the refusal explains itself, and the admin can rename), and consider in M4 refusing at add time a handle that is the start of an agent's name or has an agent's name as its start, so that the collision cannot arise.
